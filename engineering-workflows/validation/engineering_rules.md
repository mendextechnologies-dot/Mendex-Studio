# Engineering rules

Keep SI quantities explicit and retain existing API unit suffixes (including mm/mm2/degrees C where required). Discover registered calculation input schemas and preserve model assumptions and limits. Do not convert units silently, invent vendor/device/core properties, substitute default product values or assert regulatory compliance. A numerical check, simulated evidence, measured evidence and authorized engineering judgment are distinct. Unsupported calculations/tools/physical checks remain NOT_EVALUATED. No hardware control, automatic design approval or manufacturing release.
