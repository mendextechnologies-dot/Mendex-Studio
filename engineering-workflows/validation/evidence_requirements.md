# Evidence requirements

Preserve exact original native inputs, raw solver files, logs, actual versions, units, timestamps and SHA-256. Registered artifacts retain a unique copy and original hash. Validation evidence must be associated with the same revision/specification and have explicit value/bounds/units, kind and source. CALCULATED, SIMULATED, MEASURED and MANUAL are not interchangeable. Numerical criteria and identities are caller assertions, not authenticated approval. A missing/changed file or specification invalidates effective evaluation without rewriting history. Synthetic software fixtures never establish real engineering or physical results. A legacy report without original trusted hashes stays UNVERIFIED_LEGACY.
