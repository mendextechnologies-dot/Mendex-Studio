# Generic agent prompt library

Implemented under `engineering-workflows/`: master instructions, nine stage prompts, three validation rule documents and six report/specification/review templates. Each stage contains thirteen operational sections and names only existing MCP operations. Lifecycle definitions remain authoritative; prompts are guidance and cannot approve work. Default review gates and unimplemented physical/native checks remain explicit. The library is agent-independent, uses no product-specific numeric requirements, and preserves existing record/revision/evidence contracts.

Validation checks stage coverage, all required sections, discovered tool names and the absence of product-specific preset requirements. Generic templates contain placeholders only; they are not engineering evidence. CLI examples use implemented `engineering`/`lifecycle` groups rather than invented commands. See the master prompt for retry, staleness, review and source rules.
