# Mendex Engineering Studio v0.1.0 — foundation

Local Python/PySide6/SQLite engineering framework with revisioned products/specifications, native-tool discovery, manual evidence-backed validation, draft HTML/JSON dossiers, VS Code/native-file handoff and diagnostics.

The foundation includes transformer/converter/device/PCB workspace shells, complete adapter extension contracts, versioned engineering rule definitions, data-only plugin loading, a read-only AI interface with an unavailable default provider, and persisted simulation availability requests. Solver execution remains NOT_SUPPORTED; no numerical engineering results are generated.

Verification: 28 local tests, native Windows desktop smoke captures, actual primary-workstation VS Code/Explorer/document-window observations, fresh-environment wheel installation and backup/restore checks. Independent-engineer/second-machine qualification remains unperformed. A source release does not represent engineering, manufacturing or safety approval.

Install Python 3.13, clone the source and follow README.md or scripts/bootstrap.ps1. Native EDA tools remain separately installed. Windows file-version metadata is informational; runtime tool benchmarks remain unqualified. Manual packages include a wheel, source archive and SHA-256 checksums. No CI/CD, deployment, hardware control or manufacturing release is included.

Database schema is now v3. Before upgrading, close Studio and back up .mendex and products together. Restore a matching backup when reverting to an older application. See docs/requirements-matrix.md and docs/known-limitations.md for scope and remaining limitations.
