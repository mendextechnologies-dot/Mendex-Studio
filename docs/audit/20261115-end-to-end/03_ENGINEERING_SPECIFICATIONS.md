## Evidence distinctions and dependencies

Specification schema: `src/mendex_core/models.py:Specification`; candidate envelope: `src/mendex_core/design/synthesis.py:TOPOLOGY_APPLICABILITY_MATRIX`; exact generation inputs: `design/requests.py`; seven calculators: `engineering_records/calculations.py`; waveform behavior: `design/ltspice_runner.py`; thermal/WCCA: `design/thermal_engine.py`, `design/wcca_engine.py`; insulation: `intelligence/calculations.py` and `integrations/adapters/copper_kicad_adapter.py`.

Software input validation, a calculation result, a solver exit code, simulated requirement acceptance, a measured result and engineering authorization are six distinct things. Only cite evidence at its actual level. No supported whole-product voltage/current/power/temperature range can be certified by this audit.

Runtime dependencies observed include Python 3.13.7, installed NumPy use, Pydantic and PySide6; desktop uses React 18, TypeScript, Vite and Tauri 2 per manifests. `pyproject.toml` explicitly lists only pydantic/PySide6/pillow as base dependencies despite NumPy imports in new analysis paths. Installed-environment success does not establish clean-install reproducibility. Native library/model versions and OS compatibility must be qualified separately.
