# Engineering lifecycle transport contracts v3.1

Phase 2 record/calculator contracts use the `records.` filename prefix, generated by
`python scripts/export_engineering_record_contracts.py` (or `--check`). Canonical
models are in `src/mendex_core/engineering_records/`. These add 22 MCP/CLI operations;
see `docs/v3.1/17_SHARED_AGENT_OPERATIONS.md`. Lifecycle schemas below are unchanged.

Canonical input/configuration models: `src/mendex_core/engineering_lifecycle/models.py`.
Both CLI and MCP use `engineering_lifecycle/api.py`. These schemas are additive;
historical contracts elsewhere are unchanged.

Regenerate with `python scripts/export_lifecycle_contracts.py`; verify without writes
with `python scripts/export_lifecycle_contracts.py --check` in the project environment.

See `docs/v3.1/09_MCP_CLI_CONTRACTS.md` for operation names, JSON file formats,
idempotency, structured errors and history pagination. There is no approve operation.

Configuration and successful process checks never confer engineering, standards,
hardware or manufacturing authorization. The packaged default's review-gated stages
cannot complete without an authorized review mechanism, which is currently unavailable.
