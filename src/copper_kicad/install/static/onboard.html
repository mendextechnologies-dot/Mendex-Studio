Copper setup

    Find KiCad

    Copper works through the KiCad on this computer. Nothing in KiCad changes on this step.

    Looking for KiCad…

    Bring your KiCad setup along

    Your libraries, theme and shortcuts, ready in the KiCad Copper uses. Every file is backed up first, and one click puts it all back.

    Connect your AI apps

    Copper adds one entry to each app's settings file (after backing it up), then starts itself the way the app will, to check that it works. Your logins in those apps are not touched.

    Link GitHub

    Only needed if you want your AI to publish designs to GitHub. You can skip this and run copper link github later.

    Get the autorouter

    Freerouting draws the traces on a board. It's a one-time download, the router and a Java runtime, into Copper's own folder.

    Try a real call

    Copper starts exactly the way your AI app will start it, and answers one real request.

    Copper is ready

    Open your AI app and ask it for a board.
